# Fossick 矿井编辑器使用说明

## 打开

1. 打开 `FossickMapStudio.app`。
2. 如果 macOS 拦截，请右键 App，选择“打开”。

## 推荐流程

```text
编辑模板 -> 保存模板 -> 更新预览 -> 校验 -> 试玩
```

## 编辑模板

1. 点击左侧“打开模板库”。
2. 选择已有模板后点击“编辑模板”，或选择预设并点击“创建模板”。
3. 选择层级和画笔，在矿井区域点击或拖动绘制。
4. 点击“保存模板”。
5. 点击“返回地图预览”。

模板类型：

- 新手：矿井开头使用。
- 常规：随机参与矿井生成，需要选择难度。
- 奖励：用于藏宝阁等奖励区域。

画笔层级：

- 藏宝阁：选择固定规格后，点击目标区域的左上角放置；背景必须完整位于模板范围内。
- 地形：空格、土、石头、基岩、炸药箱。
- 奖励：矿石、金币、宝箱、收藏品。
- 道具：矿镐、雷管、炸药、雷达。
- 装饰：草、蘑菇等装饰。
- 阴影：设置初始遮挡。

## 调整生成规则

1. 点击左侧“生成规则”。
2. 调整一轮模板数量、难度比例和藏宝阁间隔。
3. 点击“应用并更新预览”。

## 查看地图预览

- “更新预览”：按当前模板和规则重新生成。
- “换一个”：更换种子。
- “向下预览”：继续查看更深的矿井。
- “隐藏阴影 / 显示阴影”：只切换预览显示，不修改模板。
- 点击格子：查看该格来自哪个模板。

地图预览不能直接编辑。需要修改时，请返回模板库。

## 试玩

1. 点击顶部“试玩”。
2. 使用矿镐、雷管、炸药和雷达检查实际效果。
3. 掉落物直接点击收集，不消耗工具。
4. 点击“返回编辑器”回到地图编辑器。
5. 点击“重置”清除本次试玩进度。

## 校验

点击顶部“校验”打开结果列表。每条问题会显示所属配置、模板 ID 和格子坐标；点击“定位”可直接打开对应模板或生成规则。

- 错误：必须修复后再试玩或交付。
- 警告：不会阻止使用，但需要确认内容是否符合预期。

## 交付数据

1. 点击顶部“打开数据目录”。
2. 将下面三个文件一起发给开发：

```text
FossickFragmentLibrary.json
FossickGenerationRules.json
FossickMapDefinition.json
```

不要从 App 包内部复制 JSON。
