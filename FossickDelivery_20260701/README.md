# Fossick 矿井编辑器交付包

交付内容：

- `FossickMapStudio_macOS_v0.7.zip`：Mac 试玩包，解压后打开 `FossickMapStudio.app`。
- `Fossick矿井编辑器使用说明.md`：给策划看的使用说明。

使用建议：

1. 先阅读使用说明。
2. 解压并打开 App。
3. 编辑模板、调整生成规则、生成地图预览。
4. 需要体验玩法时，点击顶部“试玩”。
5. 编辑完成后，在 App 中点击“打开数据目录”，把目录里的三个 JSON 文件交给开发。

数据文件默认位于：

`~/Library/Application Support/Magic Tavern/Fossick MapStudio/Fossick/MapStudio/Maps`
