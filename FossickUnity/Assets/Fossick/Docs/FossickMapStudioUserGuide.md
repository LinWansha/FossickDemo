# Fossick 矿井编辑器使用说明

## 打开

1. 打开交付包里的 `FossickMapStudio.app`。
2. 如果 macOS 提示无法打开，请右键 App，选择“打开”。
3. App 是窗口模式，可以拖动窗口大小，也可以用左上角按钮关闭。

## 推荐流程

1. 打开“模板库”。
2. 选择模板，或创建新模板。
3. 在中间区域编辑模板。
4. 点击“保存模板”。
5. 点击“更新预览”，检查生成效果。
6. 点击“校验”，确认没有错误。
7. 点击“试玩”，体验实际挖矿。
8. 点击“导出 JSON”，把数据文件交给开发。

简单记法：

```text
改模板 -> 保存模板 -> 更新预览 -> 校验 -> 试玩 -> 导出 JSON
```

## 模板库

- “打开模板库”：查看和管理所有模板。
- “创建模板”：从空白、全土、奖励层等预设创建新模板。
- “编辑模板”：进入模板编辑。
- “复制模板”：复制当前选中的模板。
- “删除模板”：删除当前选中的模板。

模板类型：

- 新手：矿井开头使用。
- 常规：正常挖矿过程中随机出现，需要设置难度。
- 奖励：藏宝阁或奖励区域。

注意：

- 模板改完后必须点“保存模板”。
- 常规模板需要设置难度。
- 奖励模板不会按常规模板规则随机出现。

## 模板编辑

1. 先选择要编辑的层级。
2. 再选择画笔。
3. 在地图格子上点击或拖动绘制。
4. 修改完成后点击“保存模板”。

常用层级：

- 藏宝阁：放藏宝阁背景。
- 地形：放空格、土、石头、基岩、炸药箱。
- 奖励：放矿石、金币、宝箱、收藏品。
- 道具：放矿镐、雷管、炸药、雷达。
- 装饰：放草、蘑菇等装饰。
- 阴影：设置初始遮挡区域。

常用规则：

- 土和石头可以被挖。
- 基岩不能被挖。
- 矿石和道具要放在可挖地形上。
- 藏宝阁背景按固定规格摆放。

## 生成规则

点击左侧“生成规则”可以调整随机生成参数。

常用设置：

- 一轮常规模板数量。
- 难度 1、2、3 的数量。
- 藏宝阁插入间隔。

改完后：

1. 点击“保存规则”。
2. 点击“应用并更新预览”。

## 地图预览

地图预览用于检查最终拼接效果。

可以做：

- 点击“更新预览”重新生成。
- 点击“换一个”更换种子。
- 点击“向下预览”查看更多矿井内容。
- 打开或关闭“阴影显示”。
- 点击格子查看来源模板。

注意：

- 预览里不能直接改地图。
- 预览不满意时，请回模板库改模板，或去生成规则改参数。

## 试玩

点击顶部“试玩”进入玩法预览。

试玩里可以：

- 用矿镐、雷管、炸药、雷达。
- 点击掉落物直接收集。
- 验证阴影、下移、奖励和道具效果。

试玩场景里：

- “返回编辑器”：回到地图编辑器。
- “重置”：清掉试玩进度，重新开始体验。

## 校验

点击顶部“校验”检查当前配置。

如果右侧显示有错误，请按提示回模板或规则里修改。

## 导出 JSON

点击顶部“导出 JSON”后，会打开数据目录。

请把目录里的这三个文件一起发给开发：

```text
FossickFragmentLibrary.json
FossickGenerationRules.json
FossickMapDefinition.json
```

不要从 App 包内部复制 JSON。以“导出 JSON”打开的目录为准。

## 常见问题

### 保存模板后预览没变化

保存模板后，还需要点击“更新预览”。

### 新模板没有出现在预览里

随机结果和种子有关，可以点击“换一个”，或继续“向下预览”。

### 阴影显示开关会改数据吗

不会，只影响预览显示。

### 掉落物点击会消耗道具吗

不会。掉落物点击后直接收集。
