# Fossick MapStudio Productization Plan

## Goal
Push MapStudio toward a production editor for designers by separating authored assets from generated preview data.

## Tasks
- [x] Treat fragment templates and generation rules as the only editable authoring data.
- [x] Convert generated mine instance UI into read-only preview and source inspection.
- [x] Remove template-to-instance application and row batch editing entry points.
- [x] Stop exporting generated row/sequence overrides from split project storage.
- [x] Update menu and mode labels to avoid implying generated map editing.
- [x] Verify C# build and storage tests compile.
